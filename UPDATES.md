# Как выпускать обновления, не теряя прогресс игроков

Прогресс игроков (деньги, вещи, машины, дом, отношения и брак, задания, покупки)
хранится в DataStore **`LifeCity_v1`** по ключу `p_<UserId>`.

## Правила

1. **Никогда не меняйте имя хранилища** (`STORE_NAME` в `src/server/Services/DataService.luau`):
   с новым именем все игроки начнут с нуля.
2. **Новые поля** просто добавьте в `defaultData()`: у старых игроков они появятся
   автоматически (функция `reconcile`), старые значения не трогаются.
3. **Изменение формата** (переименование поля, пересчёт цен, перенос данных):
   - увеличьте `DATA_VERSION` на 1;
   - добавьте функцию в `MIGRATIONS[новая_версия]`, которая переводит старые данные в новый вид.
   При входе каждое сохранение последовательно проходит все недостающие миграции.
4. Не удаляйте предметы и машины из `Config` без миграции: замените их у игроков на
   аналоги или верните деньги.

## Встроенная защита

- **Ошибка загрузки** (DataStore недоступен): данные игрока помечаются «только чтение»,
  и сервер не перезапишет его сохранение пустым профилем. Игрок видит предупреждение.
- **Старый и новый серверы одновременно**: сохранение идёт через `UpdateAsync`.
  Старый сервер не перезапишет данные, у которых версия формата новее.
- **Автосохранение** каждые 2 минуты, при выходе игрока и при закрытии сервера (`BindToClose`).
- **Покупки за Robux** сохраняются сразу и не начисляются дважды.

## Порядок выпуска обновления

1. Внесите изменения, запустите тесты (`tests/`, см. README).
2. `python3 build.py`, проверьте игру в Studio (Play / Start с 2–3 игроками).
3. **File → Publish to Roblox**.
4. В Creator Hub → игра → **⋯ → Restart Servers for Updates / Migrate to Latest Update**.
   Сервера перезапустятся мягко: перед закрытием каждый сохранит игроков (`BindToClose`),
   и игроки переедут на новую версию с сохранённым прогрессом.
