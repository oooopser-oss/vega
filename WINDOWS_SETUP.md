# Установка и запуск на Windows

## 🚀 Шаг 1: Первоначальная установка

1. Скачайте и установите **Node.js** (если не установлен): https://nodejs.org/
   - Выберите версию LTS
   
2. Откройте Command Prompt (cmd) или PowerShell

3. Перейдите в папку проекта:
```bash
cd C:\path\to\vega
```

4. **Запустите установку** (двойной клик на файл):
```
setup.bat
```

Это установит всё необходимое и создаст файл `.env` с вашими учётными данными.

## 📸 Шаг 2: Запуск мониторинга

После установки вы можете запустить мониторинг одним из способов:

### Способ А: Запустить один раз

Двойной клик на один из файлов:

**Все кластеры:**
- **`run-all.bat`** — все кластеры, все темы
- **`run-all-tech.bat`** — все кластеры, технологическое оборудование
- **`run-all-concept.bat`** — все кластеры, новый концепт

**Кластер 46:**
- **`run-c46-tech.bat`** — технологическое оборудование
- **`run-c46-concept.bat`** — новый концепт

**Кластер 49:**
- **`run-c49-tech.bat`** — технологическое оборудование
- **`run-c49-concept.bat`** — новый концепт

**Кластер 51:**
- **`run-c51-tech.bat`** — технологическое оборудование
- **`run-c51-concept.bat`** — новый концепт

Скриншоты будут сохранены в папку `screenshots\YYYY-MM-DD\`

## ⏰ Шаг 3: Автоматический запуск каждый час

### Способ: Windows Task Scheduler (Планировщик задач)

1. **Откройте Планировщик задач:**
   - Нажмите `Win + R`
   - Введите: `taskschd.msc`
   - Нажмите Enter

2. **Создайте новую задачу:**
   - Слева: "Создать простую задачу"
   - Имя: `Website Monitoring`
   - Описание: `Автоматический мониторинг заявок`
   - Нажмите "Далее"

3. **Триггер (расписание):**
   - Выберите: "Ежечасно"
   - Нажмите "Далее"

4. **Действие:**
   - Выберите: "Запустить программу"
   - Программа: `C:\path\to\vega\run-all.bat`
   - Замените `C:\path\to\vega` на реальный путь к папке проекта
   - Нажмите "Далее"

5. **Завершение:**
   - Отметьте: "Открыть диалоговое окно свойств"
   - Нажмите "Готово"

6. **В открывшемся окне:**
   - Вкладка "Общие": отметьте "Выполнить с наивысшими привилегиями"
   - Вкладка "Условия": уберите галочку "Пуск только если компьютер работает от сети"
   - Нажмите "ОК"

Теперь мониторинг будет запускаться **каждый час автоматически**.

## 🔧 Частые вопросы

### Как просмотреть скриншоты?
Откройте папку `screenshots` → выберите дату → откройте `.png` файл

### Как изменить расписание?
Откройте `setup.bat` → отредактируйте интервал в Task Scheduler

### Как отключить мониторинг?
Откройте Планировщик задач → найдите `Website Monitoring` → отключите

### Как обновить учётные данные?
Отредактируйте `.env` файл в корне папки проекта
