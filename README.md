# СептикДом

Сайт продажи и монтажа септиков и станций глубокой очистки. Next.js (App Router) + TypeScript +
Tailwind CSS.

## Стек

- Next.js 16, React 18, TypeScript (strict)
- Tailwind CSS 3
- `@phosphor-icons/react` для иконографики
- `next/font/google` (Inter + Outfit, с кириллицей)

## Структура

- `app/` — страницы (App Router)
- `components/` — UI-компоненты
- `data/` — контент (товары, услуги, портфолио, отзывы, регионы, цены)
- `config/site.ts` — контакты, слоган, соцсети
- `services/` — отправка заявок (API-роут `/api/lead` + стабы Telegram/MAX/CRM через переменные окружения)
- `lib/` — форматирование, валидация телефона

## Переменные окружения (опционально)

```
TELEGRAM_BOT_TOKEN=
TELEGRAM_CHAT_ID=
MAX_WEBHOOK_URL=
CRM_WEBHOOK_URL=
```

Без них заявки просто сохраняются как успешные без фактической отправки (удобно для разработки).

## Фотографии

Главное фото (фасад дома) и фото монтажа (установка бетонного кольца септика) — лицензированные
фотографии Adobe Stock. Карточки товаров используют нейтральную иллюстрацию-плейсхолдер вместо
постановочных фото конкретного оборудования, чтобы не выдавать иллюстрацию за официальное фото
производителя.
