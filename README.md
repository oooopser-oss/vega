# Жизнь Города: Первоуральск (Roblox)

Ролевая игра в духе GTA + The Sims в **настоящем Первоуральске**. Улицы, дома,
Нижнешайтанский пруд, ж/д станция и парки построены по открытым данным
OpenStreetMap. Игровые здания стоят на местах реальных объектов:
администрация города, ОМВД, городская больница №1, Сбербанк, ЗАГС, «Пельменная»,
цветочный магазин, Парк культуры и отдыха.

## Как открыть игру

1. Скачайте файл **`LifeCity.rbxlx`** из репозитория.
2. Откройте Roblox Studio → **File → Open from File…** → выберите `LifeCity.rbxlx`.
3. Нажмите **Play** (или **Test → Start** с 2–3 игроками, чтобы проверить отношения и полицию).
4. Чтобы прогресс сохранялся, опубликуйте место (**File → Publish to Roblox**) и включите
   **Game Settings → Security → Enable Studio Access to API Services**.

Город строится скриптом при запуске сервера (несколько секунд), поэтому в режиме
редактирования карта пустая. Это нормально.

Пересобрать `.rbxlx` из исходников: `python3 build.py`. Также можно работать через
[Rojo](https://rojo.space): `rojo serve` (проект `default.project.json`).

## Что есть в игре

| Система | Описание |
|---|---|
| **Роли** | Мирный житель, Полиция, Спецслужбы, Медик, Преступник (лимиты мест на сервер) |
| **Работа** | Кассир, повар, офис, грузчик, курьер, патруль, оперативник, врач. Метка задания + клавиша E → зарплата |
| **Потребности** (как в Sims) | Сытость, энергия, гигиена, настроение. Еда, сон, душ, отдых в парке |
| **Экономика** | Наличные и карта, банкоматы, магазины, инвентарь |
| **Бонус за регистрацию** | **10 000$** на карту каждому игроку при первом входе |
| **Ежедневные задания** | 3 новых задания каждый день (одно под роль игрока), награды, бонус дня 1500$ |
| **Ежедневный вход** | Бонус за вход растёт с серией дней подряд (до ×7) |
| **Дома** | 12 домов в частном секторе. Кровать, душ, ТВ, холодильник, личная дверь, звонок |
| **Машины** | Седан, внедорожник, спорткар, лимузин (пасс), патрульные машины. Угон для преступников |
| **Отношения** | Знакомство → симпатия → свидания → «встречаться» → кольцо и предложение → роспись в ЗАГСе → общий дом. Расставание и развод |
| **Преступность** | Ограбления магазинов и банка, звёзды розыска, наручники и шокер, тюрьма со сроком |
| **Медицина** | Аптечка, больничные койки, счёт за лечение после смерти |
| **Город** | Смена дня и ночи, фонари, таблички с названиями улиц, GPS с линией маршрута |
| **Монетизация** | Пассы, пакеты денег, салют; см. [MONETIZATION.md](MONETIZATION.md) |
| **Обновления** | Версионирование сохранений и миграции; см. [UPDATES.md](UPDATES.md) |

Управление: **M** — телефон (задания, работа, люди, вещи, машины, дом, GPS, магазин),
**E** — взаимодействие, **W/A/S/D** — машина, **Пробел** — встать с кровати или выйти из машины.

## Структура

```
src/shared/Config.luau          — все цены, зарплаты, роли, задания, монетизация
src/server/Main.server.luau     — запуск сервера
src/server/Services/            — системы игры (данные, роли, работа, отношения, ...)
src/server/Map/                 — сгенерированная карта Первоуральска (не править руками)
src/client/                     — интерфейс, телефон, управление машиной
tools/pervouralsk/              — скачивание и конвертация карты
tests/                          — автотесты (Lune)
build.py                        — сборка LifeCity.rbxlx
```

## Карта Первоуральска

```bash
pip install pyarrow shapely
# (опционально) заново скачать данные из Overture Maps / OpenStreetMap:
python3 tools/pervouralsk/fetch_overture.py buildings building id,geometry,height,num_floors,class,subtype,names,bbox
# пересчитать карту и игровые позиции зданий:
python3 tools/pervouralsk/convert.py
python3 build.py
```

Масштаб: 1 метр = 1,4 stud. Покрыт центр города примерно 2,6 × 3,1 км.
Игровые здания автоматически ставятся рядом с реальными адресами, лицом к ближайшей улице.

## Тесты

Тесты запускаются в [Lune](https://github.com/lune-org/lune): проверяют, что все свойства
Roblox-объектов существуют, что сервер с картой инициализируется, интерфейс открывается,
задания и миграции сохранений работают.

```bash
python3 build.py && cd tests && lune run server && lune run client && lune run quests && lune run data
```
