# Instagram Bot - Autonomous Manager

Полнофункциональный автономный бот для управления Инстаграм-аккаунтом. Бот может автоматически лайкать посты, следить за аккаунтами, публиковать контент по расписанию и выполнять другие задачи.

## ✨ Возможности

### Основные функции
- 📱 **Автоматическое лайкание** - лайки на посты по хештегам
- 👥 **Автоматическое подписывание** - подписка на пользователей из целевых аккаунтов
- 📅 **Расписание публикаций** - автоматическая публикация постов в определённое время
- 📊 **Статистика** - отслеживание активности и результатов
- 🛡️ **Защита от блокировки** - суточные лимиты для избежания обнаружения
- ⚙️ **Гибкая конфигурация** - легко настраиваемые параметры
- 📝 **Управление контентом** - простое добавление и удаление постов
- 🔄 **Фоновое выполнение** - работает как служба

### Расширенные функции (Автономный Workflow)
- 🔍 **Поиск похожих каналов** - автоматическое обнаружение релевантных аккаунтов
- 📰 **Кураторство контента** - анализ и отбор лучшего контента по релевантности
- ✏️ **Рерайт контента** - интеллектуальная переработка текста в разных стилях
- 🎯 **Оптимизация описаний** - адаптация под алгоритм Инстаграма
- 🖼️ **Подбор изображений** - автоматический выбор фото по тексту
- 🤖 **Полный автономный цикл** - от поиска до публикации без участия

## 📋 Требования

- Python 3.8+
- pip
- Instagram аккаунт

## 🚀 Установка

### 1. Клонируйте репозиторий
```bash
git clone https://github.com/oooopser-oss/vega.git
cd vega
```

### 2. Установите зависимости
```bash
pip install -r requirements.txt
```

### 3. Настройте конфигурацию
```bash
cp .env.example .env
```

Отредактируйте `.env` файл и добавьте ваши учётные данные:
```env
INSTAGRAM_USERNAME=ваш_логин
INSTAGRAM_PASSWORD=ваш_пароль
TARGET_HASHTAGS=#photography,#instagram
TARGET_ACCOUNTS=popular_account,another_account
```

## 💻 Использование

### Инициализация (первый запуск)
```bash
python main.py setup --username your_username --password your_password
```

### Запуск бота
```bash
python main.py start
```

Бот будет работать в фоне и выполнять запланированные задачи.

### Управление контентом

#### Добавить пост
```bash
python main.py content add --image /path/to/image.jpg --caption "Ваше описание поста" --schedule-time 14:00
```

#### Просмотреть все посты
```bash
python main.py content list
```

#### Удалить пост
```bash
python main.py content delete --post-id 1
```

#### Статистика контента
```bash
python main.py content stats
```

### Управление хештегами

#### Установить целевые хештеги
```bash
python main.py hashtags set --hashtags "#photography,#instagram,#nature"
```

### Управление аккаунтами

#### Установить целевые аккаунты
```bash
python main.py accounts set --accounts "instagram,natgeo,nytimes"
```

### Ручные действия

#### Лайкнуть посты по хештегам
```bash
python main.py like --limit 10
```

#### Подписаться на подписчиков аккаунта
```bash
python main.py follow --username target_user --amount 20
```

### Проверка статуса
```bash
python main.py status
```

## 🤖 Автономный Workflow (Поиск и Кураторство)

Новый расширенный функционал для полностью автономного управления контентом!

### Обнаружение похожих каналов
```bash
python main.py workflow-cmds discover --min-relevance 0.5
```
Бот найдёт каналы, похожие на ваши целевые, и отберёт наиболее релевантный контент.

### Рерайт контента
```bash
python main.py workflow-cmds rewrite --text "Ваш текст" --style engaging
```
Доступные стили: `engaging` (привлекательный), `professional` (профессиональный), `casual` (casual)

**Примеры:**
```bash
# Привлекательный рерайт
python main.py workflow-cmds rewrite --text "Красивый закат" --style engaging

# Профессиональный тон
python main.py workflow-cmds rewrite --text "Новое обновление" --style professional

# Casual стиль
python main.py workflow-cmds rewrite --text "Это крутой продукт" --style casual
```

### Подбор изображений к тексту
```bash
python main.py workflow-cmds match-images --text "Описание поста" --limit 3
```
Требует наличия папки `content/images/` с изображениями. Бот автоматически подберёт наиболее релевантные фото.

### Полный автономный цикл
```bash
python main.py workflow-cmds full-workflow --min-relevance 0.5 --auto-schedule --image-dir content/images
```

Этот команда выполняет полный процесс:
1. 🔍 Поиск похожих каналов
2. 📰 Анализ и отбор контента
3. ✏️ Переработка текста
4. 🖼️ Подбор изображений
5. 📅 Автоматическое планирование публикаций

### Отчёт о workflow
```bash
python main.py workflow-cmds report
```
Показывает статистику и результаты последнего workflow.

## ⚙️ Конфигурация

### Основные параметры в `.env`:

| Параметр | Описание | По умолчанию |
|----------|---------|--------------|
| `INSTAGRAM_USERNAME` | Логин аккаунта | - |
| `INSTAGRAM_PASSWORD` | Пароль аккаунта | - |
| `AUTO_LIKE` | Включить автолайки | True |
| `AUTO_FOLLOW` | Включить автоподписки | True |
| `AUTO_DM` | Включить автосообщения | False |
| `DAILY_LIKES_LIMIT` | Макс. лайков в день | 100 |
| `DAILY_FOLLOWS_LIMIT` | Макс. подписок в день | 50 |
| `TARGET_HASHTAGS` | Целевые хештеги | - |
| `TARGET_ACCOUNTS` | Целевые аккаунты | - |
| `POST_SCHEDULE` | Время публикаций (HH:MM) | 08:00,14:00,20:00 |

## 📅 Расписание

По умолчанию бот выполняет следующие задачи:

- **Каждые 2 часа** - автолайки по хештегам
- **Каждые 3 часа** - автоподписка на пользователей
- **По расписанию** - публикация постов (08:00, 14:00, 20:00)
- **В 00:00** - сброс дневной статистики

## 🔒 Безопасность

### Рекомендации:

1. **Не используйте пароль в открытом виде** - используйте переменные окружения
2. **Установите разумные лимиты** - избегайте излишней активности
3. **Используйте прокси** - для дополнительной анонимности (опционально)
4. **Следите за логами** - проверяйте `logs/` папку для отслеживания ошибок
5. **Соблюдайте правила Instagram** - используйте бот ответственно

⚠️ **Внимание**: Использование ботов может нарушить правила Instagram. Используйте с осторожностью!

## 🐛 Решение проблем

### Ошибка: "Login failed: Invalid credentials"
- Проверьте корректность логина и пароля в `.env`
- Убедитесь, что аккаунт активен

### Ошибка: "Action blocked"
- Снизьте дневные лимиты в конфигурации
- Используйте прокси
- Подождите несколько часов перед следующей попыткой

### Логи находятся в папке `logs/`
```bash
tail -f logs/bot_20240101.log
```
