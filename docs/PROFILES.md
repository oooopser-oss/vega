# Профили мониторинга

Система профилей позволяет быстро запускать мониторинг для заранее настроенных комбинаций **кластер + тема обращения**.

## Доступные профили

### Кластер 46 (Екатеринбург)

- **`c46-tech`** — Технологическое оборудование
- **`c46-concept`** — Новый концепт

### Кластер 49 (Екатеринбург)

- **`c49-tech`** — Технологическое оборудование
- **`c49-concept`** — Новый концепт

### Кластер 51 (Екатеринбург)

- **`c51-tech`** — Технологическое оборудование
- **`c51-concept`** — Новый концепт

### Мультикластеры

- **`all-tech`** — Все кластеры (46, 49, 51) - Технологическое оборудование
- **`all-concept`** — Все кластеры (46, 49, 51) - Новый концепт
- **`all`** — Все кластеры - Все темы

## Использование

### 🚀 Быстрый запуск

```bash
# Для конкретного профиля
npm run cli:c46-tech          # Кластер 46 - Технологическое
npm run cli:c49-concept       # Кластер 49 - Концепт
npm run cli:all               # Все профили подряд
```

### 📋 Просмотр профилей

```bash
npm run cli:profiles
```

### 🔧 CLI с профилем

```bash
npm run cli -- --profile c46-tech

# С дополнительными фильтрами
npm run cli -- --profile c46-tech --date-from 2024-09-01 --date-to 2024-09-30
```

## Расписание с профилями

### Запуск каждый час

```bash
# Запускать только Кластер 46 - Технологическое каждый час
npm run scheduler -- --interval=3600000

# Потом отредактировать src/scheduler.js для запуска конкретного профиля
```

### Запуск разных профилей в разное время

Можно использовать cron (Linux/Mac) или Task Scheduler (Windows):

```bash
# Технологическое оборудование - каждый день в 9:00
0 9 * * * cd /path/to/vega && npm run cli:all-tech

# Все профили - каждый день в 18:00
0 18 * * * cd /path/to/vega && npm run cli:all
```

## Запуск всех профилей подряд

```bash
npm run cli:all
```

Последовательно запустит мониторинг для:
1. c46-tech (Кластер 46 - Технологическое)
2. c46-concept (Кластер 46 - Концепт)
3. c49-tech (Кластер 49 - Технологическое)
4. c49-concept (Кластер 49 - Концепт)
5. c51-tech (Кластер 51 - Технологическое)
6. c51-concept (Кластер 51 - Концепт)
7. all-tech (Все кластеры - Технологическое)
8. all-concept (Все кластеры - Концепт)
9. all (Все кластеры - Все темы)

Скриншоты будут отправлены в Max.ru и Telegram (если включены).

## Создание собственных профилей

Отредактируйте `src/profiles.js`:

```javascript
export const profiles = {
  'my-profile': {
    name: 'Мой профиль',
    filters: {
      clusters: ['Кластер Екатеринбург 46'],
      theme: ['tech_equipment'],
      status: 'all',
    },
  },
  // ... другие профили
};
```

Потом используйте:
```bash
npm run cli -- --profile my-profile
```

## Интеграция с Telegram и Max.ru

Все профили автоматически отправляют скриншоты в Telegram и Max.ru, если они включены в `.env`:

```bash
TELEGRAM_ENABLED=true
MAX_ENABLED=true
```

Каждый скриншот будет содержать информацию о:
- Времени выполнения
- Названии профиля
- Используемых фильтрах (кластер, тема)

## Примеры

### Пример 1: Мониторинг Технологического оборудования

```bash
# Запустить мониторинг всех кластеров для технологического оборудования
npm run cli:all-tech

# Результат: 3 скриншота (по одному для каждого кластера)
# Все скриншоты отправятся в Max и Telegram
```

### Пример 2: Ежедневный мониторинг всех профилей

```bash
# Запустить все профили и отправить в группы
npm run cli:all

# Результат: 9 скриншотов для всех комбинаций
```

### Пример 3: Плановый мониторинг конкретного кластера

```bash
# Запуск мониторинга Кластера 49 с указанием даты
npm run cli -- --profile c49-tech --date-from 2024-09-01 --date-to 2024-09-30
```
