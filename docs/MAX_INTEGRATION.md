# Max.ru (VK Max) Интеграция

Инструкция по настройке отправки скриншотов в группу Max.ru.

## Что такое Max.ru?

Max (ранее MyWorld) — это российский мессенджер и социальная сеть от VK.com (Mail.ru Group).

Сайт: https://max.ru/

## Получение API токена

### Способ 1: Через VK API (рекомендуется)

Max.ru использует VK API для отправки сообщений. Нужно получить токен через VK:

1. Перейдите на https://dev.vk.com
2. Войдите в аккаунт VK
3. Создайте приложение:
   - Выберите "Веб-приложение"
   - Заполните название и прочие данные
4. Получите **Application ID** и создайте токен доступа

Или используйте токен сообщества VK (если группа подключена к VK):
- Перейдите в параметры группы
- Вкладка "Работа с API"
- Создайте токен доступа

### Способ 2: Через Max.ru интерфейс

Если Max.ru имеет собственный API (уточнить):

1. Перейдите на https://max.ru/dev (если существует)
2. Создайте приложение
3. Получите Access Token

## Получение ID группы

### Через VK:
1. Откройте группу в VK
2. Посмотрите URL группы: `https://vk.com/club12345678`
3. ID группы: `-12345678` (с минусом для отправки сообщений)

### Через Max.ru:
1. Откройте группу в Max
2. Скопируйте ID из URL

## Настройка в приложении

1. Скопируйте `.env.example` в `.env`:
```bash
cp .env.example .env
```

2. Отредактируйте `.env` и добавьте:
```bash
# Max.ru интеграция
MAX_ENABLED=true
MAX_ACCESS_TOKEN=your_access_token_here
MAX_CHAT_ID=-12345678
```

Где:
- `MAX_ACCESS_TOKEN` — токен доступа из VK API
- `MAX_CHAT_ID` — ID группы (отрицательное число)

## Проверка настроек

Запустите мониторинг:
```bash
npm run monitor
```

Если всё настроено корректно, скриншот будет отправлен в группу Max.

## Примеры использования

### Через CLI:
```bash
npm run cli -- --send-telegram  # Будет отправлено в Max (если включено)
```

### Через API:
```bash
npm run api
curl -X POST http://localhost:3000/api/monitor
```

## Возможные ошибки

### "Max.ru не настроен"
- Проверьте, что `MAX_ENABLED=true` в `.env`
- Проверьте токен и ID группы

### "Access token invalid"
- Токен может быть протухшим или неправильным
- Получите новый токен в разработчика VK

### "Chat not found"
- Проверьте ID группы (должен быть отрицательным)
- Убедитесь, что бот добавлен в группу с правами на отправку сообщений

## Автоматическая отправка

Чтобы скриншоты отправлялись автоматически каждый час:

```bash
npm run scheduler:hourly
```

## Отправка уведомлений об ошибках

Если мониторинг завершится с ошибкой, в Max будет отправлено уведомление:

```
❌ Ошибка мониторинга

Текст ошибки...

Время: 01.09.2024 14:30:45
```

## Дополнительно

Для одновременной отправки в несколько мессенджеров (Telegram + Max):

1. Включите обе интеграции в `.env`:
```bash
TELEGRAM_ENABLED=true
TELEGRAM_BOT_TOKEN=...
TELEGRAM_CHAT_ID=...

MAX_ENABLED=true
MAX_ACCESS_TOKEN=...
MAX_CHAT_ID=...
```

2. Запустите мониторинг:
```bash
npm run monitor
```

Скриншот будет отправлен в обе группы одновременно.
